# Their words → what they mean

Copy this file to `references/word-list.md` and make it yours. The rows below are
illustrative examples of the kind of entry that earns its place; delete the ones that
don't apply and keep the format.

A living word list. Look up every everyday phrase here before deciding what the person
wants. **Add to it every time they correct a reading, or a new shortcut works.** Format:
`"their words"` → meaning · source (memory file or job, date).

Their meaning wins over the textbook meaning and over the raw transcript.

---

## 1. Dictation mishears (sounds-like)

| They type / dictation gives | They mean | Source |
|---|---|---|
| "wish" (in a sound note) | a **whoosh** sound effect | reel sound notes, example |
| a near-homophone of a tool's name | **that tool** (check it against the tools they actually use) | example |
| "Rye Creative" | the studio's name, spelled the studio's way | example |
| "SEO1 keywords" | SEO keywords: a caption packed with search phrases, plus a few hashtags | post caption, example |
| a number or idiom said aloud + "write it as…" | their spelling instruction beats verbatim | captions, example |

When a name sounds odd, try the sounds-like reading against their known tools, clients
and pages before treating it as new.

## 3. Revision words (on something already made)

| Their words | Means | Source |
|---|---|---|
| trailing "yeah it's fine / that's fine / leave it / actually no" | **cancels** the request just before it. Say back what you did NOT change | example |
| "fast-forward it a bit" (on a clip they accepted) | same clip, **later in-point**, normal speed. Never swap it, never speed-ramp | example |
| "make it like this" (+ reference) | copy the **format**, then re-derive placement for this footage | example |
| "recreate this", "I want exactly the same" | **replicate** element by element | example |
| "in front, don't overlap me" | shrink the speaker so the graphics own the freed space, with no overlap | example |
| "when I say X, show X" | cut the visual to their word, landing a few frames after it | example |
| "go on" | keep moving forward; don't make them choose between topics | example |

## 4. Camera, light and edit words

| Their words | Term |
|---|---|
| "zoom in", "zoom in from the top" | **slow push-in / dolly-in** (not a flat digital zoom), usually from a high angle |
| "from the top" | high angle *or* overhead. **Ambiguous**: if it changes the build, ask which |
| "make it dreamy", "background blurred" | shallow depth of field / bokeh |
| "slow then suddenly fast" / "moving then stops dead" | speed ramp / freeze frame |
| "voice starts before the clip" / "voice keeps going over the next clip" | J-cut / L-cut |

## 5. Action phrases (each one runs a known routine)

| Their words | Routine |
|---|---|
| "sync it in" + a zip or handoff | extract **everything** as-is, nested zips too, verify every file, then run the pack's own sync steps |
| "save it for my page" | copy the finished file to that page's delivery folder |
